# ZCode Rusifikator — плагин 🇷🇺

Плагин для [ZCode](https://zcode.z.ai): устанавливает и сопровождает **полный русский перевод интерфейса** (~5 000 строк) настольного приложения ZCode.

Это упаковка проекта [DevGenHub/zcode-rusifikator](https://github.com/DevGenHub/zcode-rusifikator) в формат плагина: навык + слэш-команда + автопроверка после обновлений.

## Что внутри

| Компонент | Что делает |
|---|---|
| **Хук** SessionStart (`ensure-ru.js`) | Проверяет маркер перевода в `app.asar`. Всё на месте → тихо. Слетел после обновления → **авто-восстановление без ваших действий**: тихо собирает патч под новую версию и показывает окно «Требуется перезапуск ZCode» с кнопками «Перезапустить сейчас» / «Позже» |
| **Навык** `rusifikator` | Полный маршрут через агента: dry-run → перевод новых строк → установка. Срабатывает на «накати русификатор» |
| **Команда** `/rusifikator` | Явный запуск установки |

**Авто-режим после обновления ZCode:**
1. Обновление заменило `app.asar` → при первом старте сеанса хук замечает это и тихо запускает восстановление;
2. Патч готов → появляется окно «Требуется перезапуск ZCode» (перед нажатием убедитесь, что агент не выполняет задачу);
3. «Перезапустить сейчас» — приложение закроется, патч встанет, ZCode откроется снова — интерфейс русский (язык выбирается автоматически по системе);
4. «Позже» — фоновый помощник дождётся вашего обычного закрытия ZCode и сделает то же самое.

Сам перевод применяется скриптом локально к `app.asar` вашей установки (с бэкапом и проверкой целостности). Никакого сетевого взаимодействия, телеметрии нет.

## Установка

### Через маркетплейс ZCode

1. **Settings → Plugin Management → Discover** → кнопка **+**
2. Добавьте маркетплейс: `https://github.com/DevGenHub/zcode-rusifikator-plugin`
3. Установите плагин **zcode-rusifikator**

### Вручную (если маркетплейс не подхватился)

```cmd
git clone https://github.com/DevGenHub/zcode-rusifikator-plugin
xcopy /E /I zcode-rusifikator-plugin\skills\rusifikator "%USERPROFILE%\.zcode\skills\rusifikator\"
```

> Если скилл уже установлен вручную — удалите старую копию (`%USERPROFILE%\.zcode\skills\rusifikator`): пользовательские навыки имеют приоритет над плагинными, и плагинные обновления не применятся.

## Использование

- Скажите агенту: **«накати русификатор»** — или введите **`/rusifikator`**
- Первый запуск: скрипт патчит `app.asar`; если ZCode запущен — закройте его (трей → Выход), приложение перезапустится само уже по-русски
- После каждого обновления ZCode повторите один раз

## Требования

- Windows 10/11, ZCode Desktop 3.x
- Node.js ≥ 18 (для установщика и хука)

## Оговорка

Неофициальный проект, автор не связан с Z.ai / ZCode. ZCode и Z.ai — товарные знаки их владельцев. Скрипт модифицирует только локально установленную копию приложения. Используйте на свой риск.

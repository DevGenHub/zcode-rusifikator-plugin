# Русификатор интерфейса ZCode

ZCode официально поддерживает только en-US и zh-CN. Скилл добавляет полноценную локаль `ru-RU` (~5000 строк + меню + служебные окна) прямо в `app.asar` и учит приложение выбирать русский (по языку системы или через выпадающие списки в настройках).

## Как это работает (кратко о механизме)

- Каталоги переводов лежат внутри `app.asar`:
  - рендерер: `out/renderer/assets/IntlProvider-*.js` — карта `g={"zh-CN":p,"en-US":m}`, валидатор `function y(e)`, системный резолвер `startsWith('zh')?'zh-CN':'en-US'`, выборка `formatMessage`;
  - настройки (дропдауны языка, гарды, нормализатор): `out/renderer/assets/styles-*.js`;
  - нативные меню/трей: объект `pp` в `out/main/chunk-*.js` (выбор `pp[t]??pp[Yr]`);
  - small-окна: `cua-permission-panel-*.js`, `process-monitor-*.js`;
  - «О программе» (объект `NK`), shell-меню (`OV`/`NV`): `out/main/index.js`;
  - zod-схемы настроек `.enum(["zh-CN","en-US"])` и `.enum(["system","zh-CN","en-US"])` — в main-chunk, host-чанке и scheduler (иначе сохранение `locale:"ru-RU"` отбрасывается).
- Скилл добавляет секцию `"ru-RU"` во все каталоги, патчит резолвер/валидаторы/списки, пересобирает asar (пересчитывает offset/size/SHA256-integrity в заголовке) и проверяет целостность и синтаксис каждого патченного файла.

## Применение

Запускай из любой папки (пути скрипт берёт сам; файл asar — `%LOCALAPPDATA%\Programs\ZCode\resources\app.asar`):

```
node "<папка скилла>\assets\apply-russian.js" --dry-run   # проверка якорей и покрытия словаря
node "<папка скилла>\assets\apply-russian.js"             # полная сборка + установка
node "<папка скилла>\assets\apply-russian.js" --asar "C:\...\app.asar"  # нестандартный путь
```

Что делает полный запуск:

1. Проверяет, не русифицирован ли уже asar (тогда выходит).
2. Извлекает текущий en-каталог из IntlProvider-чанка; сверяет со словарями `assets/dict/*.json`.
   - Если появились **новые ключи** (после обновления ZCode) — пишет `assets/work/missing-keys.json` (ключ → английский текст) и останавливается. **Переведи** эти значения сам и сохрани как `assets/dict/dict-new-01.json` (формат `{"ключ": "перевод"}`; сохраняй плейсхолдеры `{name}` и ведущие/хвостовые пробелы), затем запусти снова.
3. Применяет 23 патча (каждый якорь обязан встретиться ровно `expect` раз — иначе стоп).
4. Пересобирает asar и проверяет: разбор заголовка, побайтовое совпадение всех файлов, integrity-хэши, синтаксис патченных чанков (ESM-парс).
5. Установка:
   - если ZCode **закрыт** — бэкап `app.asar.ru-backup-<дата>` и подмена сразу;
   - если ZCode **запущен** (файл EBUSY) — ставит фонового помощника `%LOCALAPPDATA%\Programs\ZCode\resources\ru-apply\apply-when-closed.js` (detached node-процесс). Помощник ждёт закрытия приложения (до 3 ч), подменяет файл, проверяет и **сам перезапускает ZCode**. Журнал: `resources\ru-apply\apply.log`.

Сообщи пользователю: **закройте ZCode полностью (значок в трее → Выход)** — приложение перезапустится уже с русским интерфейсом. Язык выбирается автоматически («Как в системе»); также можно выбрать «Русский» в Настройках или в быстрых настройках сайдбара.

## Откат

`%LOCALAPPDATA%\Programs\ZCode\resources\ru-apply\rollback-russian.bat` (закрывает ZCode, возвращает оригинальный asar из бэкапа). Либо вручную: переименовать `app.asar.ru-backup-*` обратно в `app.asar`.

## Рекогносцировка после больших обновлений

Если dry-run пишет, что якорь не найден (структура/минификация изменились), найди новые места руками. Скачай/распакуй asar или ищи прямо в бинарнике (`node` + чтение файла, скрипт-парсер asar: первые 8 байт — размеры, затем JSON-заголовок с offset/size/integrity, данные с `8+headerSize`):

1. **Карта каталогов рендерера**: ищи `={"zh-CN":` — рядом будет `"en-US":`; имена переменных (`p`, `m`, `g`) могут смениться. Скрипт находит их сам по регулярке; если не нашёл — посмотри контекст вокруг `"en-US"` в IntlProvider-чанке.
2. **Резолвер языка**: ищи `startsWith(\`zh\`)` рядом с `` `zh-CN` `` и `` `en-US` `` (может переехать или обрасти вариантами).
3. **Валидатор**: `e===\`zh-CN\`||e===\`en-US\`` или перечисление через массив/Set.
4. **zod-схемы**: `.enum(["zh-CN","en-US"])` и `.enum(["system","zh-CN","en-US"])`.
5. **Дропдауны языка в настройках**: ищи `settings.locale.zh-CN` в styles-чанке — рядом jsx-элементы опций (добавь опцию `ru-RU` по образцу).
6. **Каталог меню main-процесса**: `"tray.menu.quit":"Quit"` — это конец объекта `pp`; функция выбора рядом (`pp[t]??pp[Yr]`).
7. Сверь патчи в `PATCHES` (в apply-russian.js) с найденным и обнови `find`/`replace`. Логика замен не меняется: добавить `"ru-RU":{...}` соседом с en-US, добавить `"ru-RU"` в перечисления, научить резолвер правилом `startsWith('ru') ? 'ru-RU'`.

## Важно

- Не запускай два помощника параллельно: если `app.asar.new` уже лежит в resources и журнал `apply.log` свежий — помощник уже ждёт, просто закрой ZCode.
- Скрипт отказывается работать, если бэкап уже существует и текущий файл уже патченный (защита от двойного патча).
- После обновления ZCode патч слетает (asar заменяется целиком) — просто запусти скилл снова.
- Словари: `assets/dict/dict-00..11.json` (5075 ключей, полный каталог 3.11.2) — источник перевода; новые версии обычно только добавляют ключи.
